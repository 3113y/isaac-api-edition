## Browse the reference

The left navigation groups related APIs together. Expand a group to move between a base class and its specialized forms, or open **Enumerations** to select a specific enum directly.

## Choose the active API profile

- **REP / REP+** controls compatibility highlighting for the original API. Only a call signature that is unavailable in the selected base version is dimmed.
- **Original / RGON** reveals RGON additions and override details immediately beside their original API. Original calls remain visible because RGON is an injected dependency.
- **EN / 中文** switches to the matching language page while preserving the current path whenever it exists.

> Descriptions tagged as inferred are clearly marked fallbacks. Original English wording is shown whenever it is available.
