## 浏览 API 参考

左侧导航会把相关 API 归在同一个可展开分组中。可以在基础类和专用类之间切换，也可以展开 **Enumerations** 后直接选择具体枚举。

## 选择 API 配置

- **REP / REP+** 仅控制原版 API 的兼容性提示。所选基础版本不支持时，只有相应调用签名会变灰。
- **Original / RGON** 会在原 API 紧邻处显示 RGON 的新增内容和覆写说明。RGON 是注入式依赖，因此原版调用仍会保留显示。
- **EN / 中文** 会优先跳转到同一路径的另一种语言页面；若该页不存在，则回到对应语言首页。

> 标记为“推断”的说明仅在缺少原始英文说明时使用，并会明确标注。
