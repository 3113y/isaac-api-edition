# Lua API Documentation for The Binding of Isaac - REPENTOGON
___

This documentation covers the additions and modifications to the Lua API made by REPENTOGON.

It includes:

- over 800 new or improved functions
- over 200 new callbacks
- over 30 new rideable dragons
- over 60 new enums

**Non-API-related changes can be found in the "changes" tab.**
